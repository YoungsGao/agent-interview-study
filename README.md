# Agent 面试学习台

**在线使用：https://YoungsGao.github.io/agent-interview-study/**

包含 1466 道题目，支持题库浏览、搜索、重点学习路径、收藏及学习进度记录。

## 使用方式

直接打开上面的在线链接，无需安装或下载。也可以下载 `index.html` 后在浏览器中打开。

学习进度与收藏保存在当前浏览器的 localStorage 中，不会自动跨设备同步。本地文件与在线站点的学习记录相互独立。

## 更新网页

替换仓库根目录的 `index.html` 并提交到 `main` 分支，GitHub Pages 将自动重新发布。
